## Rules for Adding New Vendors

1. Determine whether the vendor can receive, store, process, or infer PHI.
2. If PHI exposure is possible, obtain a signed BAA before enablement in any PHI-handling environment.
3. If PHI exposure is excluded by design, document the exclusion mechanism here and in the relevant ADR or runbook.
4. Store signed BAAs in the legal evidence vault in object storage with restricted founder/legal access.
