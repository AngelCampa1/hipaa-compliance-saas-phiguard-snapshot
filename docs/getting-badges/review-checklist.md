# Review Checklist

Use this before copy-pasting into any platform.

## Pass 1: Platform Compliance

- [ ] SaaSHub includes categories.
- [ ] SaaSHub includes competitors.
- [ ] SaaSHub uses a real product URL, not an app login or waitlist.
- [ ] SaaSHub verification uses a domain email if available.
- [ ] AlternativeTo uses only real app types, features, platforms, and official links.
- [ ] AlternativeTo final logged-in form fields have been checked during submission.
- [ ] Product Hunt URL has no UTMs, shorteners, or tracking redirects.
- [ ] Product Hunt product name is exactly `PHIGuard`.
- [ ] Product Hunt tagline is under 60 characters.
- [ ] Product Hunt description is under 500 characters.
- [ ] Product Hunt has at least 2 gallery images before launch.
- [ ] Product Hunt thumbnail is square and under 3 MB.
- [ ] Product Hunt maker account has been in the community for at least 1 week.
- [ ] Product Hunt video, if used, is a public YouTube link.
- [ ] Product Hunt first comment asks for feedback, not upvotes.
- [ ] Product Hunt uses no more than 3 shoutouts.
- [ ] G2 profile name is exactly `PHIGuard`.
- [ ] G2 submission does not split plans into separate product profiles.
- [ ] G2 category evidence is based on current native functionality.
- [ ] G2 review request is sent only to real users.
- [ ] G2 review request does not ask for positive reviews.
- [ ] G2 review request does not discourage negative reviews.
- [ ] BetaList submission uses own-domain website.
- [ ] BetaList eligibility as recently launched or launch-stage has been confirmed.

## Pass 2: Claims And Legal Safety

- [ ] No claim says `HIPAA certified`.
- [ ] No claim says `SOC 2 certified`.
- [ ] No claim says `guaranteed compliance`.
- [ ] No claim says `zero risk`.
- [ ] No customer count is claimed.
- [ ] No revenue, growth, or usage metric is claimed.
- [ ] No G2 badge, ranking, star rating, or report placement is claimed.
- [ ] Any future earned G2 badge links to the applicable PHIGuard G2 product page and meets G2 attribution rules.
- [ ] BAA claim is limited to `included on every public plan`.
- [ ] Security claims match the public security page.
- [ ] Pricing claims match `packages/billing/src/plans.ts`.
- [ ] LAUNCH50 is described as the current launch offer only if still active.
- [ ] Screenshots contain no real PHI.
- [ ] Screenshots contain no real customer names or private production data.
- [ ] Audit-log screenshots have been redacted or regenerated before public upload.

## Pass 3: Humanizer

- [ ] First sentence says what PHIGuard does without buzzwords.
- [ ] Copy is specific to small clinics and practice administrators.
- [ ] No paragraph opens with the exact same sentence as another platform.
- [ ] No overused phrases like `revolutionary`, `game-changing`, `seamless`, `unlock`, `supercharge`, or `next-generation`.
- [ ] No exaggerated adjectives.
- [ ] Sentences are short enough to read aloud.
- [ ] Founder copy sounds like a real person and not a pitch deck.
- [ ] Calls to action ask for trial, evaluation, or feedback, not hype.

## Pass 4: Directory Fit

- [ ] SaaSHub copy emphasizes software category and competitors.
- [ ] AlternativeTo copy emphasizes alternative/comparison metadata.
- [ ] Product Hunt copy emphasizes product story, workflow, and feedback.
- [ ] G2 copy emphasizes B2B functionality and evidence.
- [ ] BetaList copy emphasizes early-stage startup fit and founder-led build.

## Pass 5: Final Copy-Paste QA

- [ ] Product name: `PHIGuard`
- [ ] Website: `https://phiguard.app`
- [ ] Signup: `https://my.phiguard.app/signup`
- [ ] Product: `https://phiguard.app/product`
- [ ] Pricing: `https://phiguard.app/pricing`
- [ ] Security: `https://phiguard.app/security`
- [ ] BAA: `https://phiguard.app/baa`
- [ ] No link accidentally points to localhost, staging, Vercel, Cloudflare preview, or a private app route.
- [ ] Source assets exist locally.
- [ ] Submission has been logged in `submission-tracker.csv`.

## After A Listing Goes Live

- [ ] Add live listing URL to `submission-tracker.csv`.
- [ ] Check whether the listing link is dofollow or nofollow.
- [ ] Confirm title and description were not edited into an inaccurate claim.
- [ ] Save moderator notes.
- [ ] For G2, claim the profile after it goes live.
- [ ] For Product Hunt, reply to every real comment during launch day.
- [ ] For BetaList, watch analytics for `source=betalist`.
