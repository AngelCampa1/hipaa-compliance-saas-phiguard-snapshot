# PHIGuard Directory Submission Kit

This folder is the copy-paste package for submitting PHIGuard to SaaSHub, AlternativeTo, Product Hunt, G2, and BetaList.

## Submission Order

1. SaaSHub
   - Ready to submit now.
   - Use a `@phiguard.app` email if possible so the product can be verified and prioritized.
   - Include competitors. SaaSHub says submissions without competitors are slowed down and put lower in the queue.

2. AlternativeTo
   - Ready to prepare now.
   - Submit while logged in, then verify any fields that are visible only inside the logged-in contribution flow.
   - Use PHIGuard as a paid, proprietary, SaaS product for online healthcare operations.

3. G2
   - Ready to request a profile, but not ready to market a badge.
   - Submit one product profile named exactly `PHIGuard`.
   - Treat this as listing and evidence work first. Do not imply review volume, rankings, awards, or G2 badge rights.

4. BetaList
   - Conditional.
   - Submit only if PHIGuard still qualifies as recently launched, launch-stage, or beta-stage. BetaList is not for mature products with significant prior coverage.

5. Product Hunt
   - Prepare now, launch only when the gallery assets and launch-day response plan are ready.
   - Product Hunt accepts a launch without a video, but the current repo does not contain a public YouTube demo or purpose-built 1270x760 gallery cards. Build those before a serious launch.

## Claim Rules

Do:

- Say PHIGuard is a HIPAA operations hub for small medical clinics.
- Say PHIGuard includes a BAA on every public plan.
- Say PHIGuard supports recurring HIPAA tasks, evidence, incidents, and append-only audit history.
- Say PHIGuard uses flat per-clinic pricing.
- Say the primary trial path is a 30-day free trial with no credit card required.

Do not:

- Claim HIPAA certification.
- Claim SOC 2 certification.
- Claim G2 awards, rankings, badges, or review counts.
- Claim customer counts, revenue, uptime, or security certifications not published on the site.
- Ask Product Hunt users for upvotes.
- Incentivize G2 reviews based on positivity.
