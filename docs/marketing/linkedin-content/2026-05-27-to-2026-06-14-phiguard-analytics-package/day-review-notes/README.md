# Day-Level Review Notes

This folder is reserved for day-level review notes after the 19 daily post files exist.

Expected future files:

- `day-01-review.md` through `day-19-review.md`.

Each reviewer should review one assigned daily batch only. Reviewers must not edit unrelated package files unless explicitly assigned.

## Reviewer Scope

For the assigned day, verify:

- Exactly 15 posts are present.
- All seven required pillars appear, with no pillar used fewer than two times.
- Each post has a traceable `source_url_or_repo_path`.
- Claims match the cited source and current PHIGuard repo truth.
- No post invents customers, traction, adoption, testimonials, case studies, or outcomes.
- No post claims PHIGuard is HIPAA-compliant, certified, or a legal guarantee.
- No post gives legal advice.
- No post includes PHI-like invented details.
- Hooks, CTAs, examples, and structures are not repetitive.
- The writing feels practical, human, and specific to small clinic operations.
- The day is ready for CSV conversion only if all posts are marked `approved`.

## Note Format

Use this structure for each future day review:

```md
# Day XX Review

Status: pending | needs fixes | approved

Files reviewed:

- `day-XX.md`

Findings:

- ...

Fixes applied:

- ...

Residual risks:

- ...
```
